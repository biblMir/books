# Админка на существующем Proxmox

Сервис ставится в отдельный непривилегированный LXC, а не в систему Proxmox. Новые тарифы и облачные функции не используются. Публичный каталог остаётся на GitHub Pages; приложение доступно редакторам только из локальной сети Proxmox.

## Состав

- `server.js` раздаёт каталог и редактор, обрабатывает API и привязывается к LAN-интерфейсу контейнера.
- `index.js` содержит общий вход, ограничение попыток, сессии, публикацию каталога, загрузку обложек и статистику GoatCounter.
- `git-store.js` читает опубликованную ветку GitHub и публикует изменения через отдельный deploy key репозитория.
- `books-admin.service` запускает приложение с отдельным системным пользователем и ограниченными правами.
- `set-password.js` меняет общий пароль, не печатая его в терминал и не сохраняя открытым текстом.

## Конфигурация в контейнере

`/etc/books-admin.env` должен быть доступен только root и содержать:

```ini
PORT=8080
SITE_DIR=/srv/books/site
REPO_DIR=/var/lib/books/repo
DEPLOY_KEY=/var/lib/books/.ssh/id_ed25519
SSH_KNOWN_HOSTS=/var/lib/books/.ssh/known_hosts
ADMIN_LOGIN=redaktor
ADMIN_PASSWORD_HASH=scrypt$...$...
SESSION_SECRET=<случайная строка не короче 32 байт>
GOATCOUNTER_CODE=lana
# GOATCOUNTER_TOKEN добавляется отдельно, если нужен просмотр статистики внутри редактора.
```

Права: `root:books-admin`, режим `0640`; сам файл не входит в репозиторий.

## Публикация в GitHub

Репозиторий сначала клонируется публично по HTTPS. Для публикации `books` в GitHub добавляется отдельный deploy key с правом записи. Приватный ключ остаётся только в контейнере в `/var/lib/books/.ssh/id_ed25519`.

Первый запуск создаёт публичный checkout и SSH remote. Если deploy key ещё не добавлен, чтение каталога работает, а публикация сообщает, что ключ надо настроить.

## Доступ редакторов

На GitHub Pages файл `admin.html` перенаправляет в приложение на внутренний адрес. Ссылка работает на компьютерах, имеющих маршрут в сеть Proxmox. Логин один для всей редакции; пароль общий и хранится в виде scrypt-хеша.

Текущий вариант использует HTTP внутри локальной сети: сетевой трафик до внутреннего сервера не шифруется. Не публикуй порт 8080 в интернет и не используй для входа пароль от других сервисов. Для внешнего доступа потребуется уже имеющийся доверенный HTTPS reverse proxy или VPN.

Изменить пароль: `sudo node /srv/books/app/backend-proxmox/set-password.js`, затем `sudo systemctl restart books-admin.service`.
