# Каталог книг biblMir

Публичный сайт: https://biblmir.github.io/books/.

- `index.html` и `books.json` — публичный каталог.
- `admin.html` — переход во внутренний редактор.
- `admin-app.html`, `admin-auth.js`, `admin-config.js` — исходники редактора, включая визуальное форматирование аннотаций.
- `backend-proxmox/` — серверная часть для отдельного LXC на уже работающем Proxmox.

Редактор рассчитан на рабочую сеть; публичный сайт остаётся на GitHub Pages. Пароль, ключи сессий и приватный deploy key в репозиторий не добавляются.
